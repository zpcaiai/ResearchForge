- 抽出即冻结。**不得因为"这篇看起来太难"而替换。** 若必须替换，记录理由并单独统计替换次数。

## 已知偏差（每一个从这个框算出的数字都必须带着这段话）

1. **HF Daily Papers 是策展的**，不是全量。它偏向可见度高的工作，而可见度高的仓库维护得更好。
   → **由此得到的复现率是上界，不是无偏估计。**
2. 窗口为 2025 Q4，探测时仓库已存在约 8–10 个月。
3. 非会议限定：arXiv 预印本与会议论文混合，与协议原定的"单一会议单一年份"不同。
4. 领域偏 LLM/多模态，与 v1 域（小规模 ML/NLP）大致吻合但不完全一致。
5. 计算量分层无法先验判定，只能事后记录。

## 本环境能测到哪一级

`git clone` 与 PyPI 可达，但**无 GPU、无数据集下载通道**。因此：

- **可测**：RL0（无代码/依赖装不上/克隆失败）与 RL1（环境可建、入口可跑）
- **不可测**：RL2 及以上（需要与论文数值比对，需算力与数据）

→ **P(RL≥3) 的决策规则本次无法评估。**
→ **P(RL≥1) < 0.40 → 停止建执行平面** 这一条**可以**评估，而它是几条规则里赌注最大的一条。
